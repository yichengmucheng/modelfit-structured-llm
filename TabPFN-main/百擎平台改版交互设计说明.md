# 百擎平台改版交互设计说明

> 文档版本：v1.0  
> 更新时间：2026-06-17  
> 作者：文程  
> 用途：向研发同事及领导说明本次前端改版的交互逻辑与页面结构

---

## 一、改版背景与目标

### 现存问题

| 问题 | 原因 | 影响 |
|------|------|------|
| 导航项过多，跳转频繁 | 项目管理、模型列表、模型训练、验证、在线推理各自独立 | 新用户不知道从哪里开始 |
| Train 指标展示误导 | TabPFN 是预训练 Transformer 模型，Train 指标无意义 | 业务方误判模型效果 |
| 样本与模型割裂 | 上传样本与选择样本分布在不同页面 | 操作路径不流畅 |
| 验证与推理分开 | 两者仅差"有无 Y 标签"，本质相同 | 增加无必要跳转 |

### 改版目标

- 导航精简为 3 项：**工作台 / 模型管理 / 样本管理**
- 模型管理内采用**引导式四步流程**，减少跳转
- 训练结果**只展示 Test 集指标**，去除 Train 指标
- 验证与推理**合并为一步**，按有无 Y 标签切换
- 上传样本支持**新上传 / 从样本库选择**两种方式

---

## 二、整体导航结构

```
百融百擎
├── 工作台                    ← 概览入口，统计 + 快捷操作 + 近期动态
├── 模型管理                  ← 核心模块
│   ├── 项目列表（默认落地页）
│   ├── 模型列表（点击项目后进入）
│   ├── 新建模型（填写基本信息）
│   └── 四步引导流程
│       ├── Step 1：选择训练样本
│       ├── Step 2：模型训练
│       ├── Step 3：验证推理
│       └── Step 4：发布
└── 样本管理                  ← 原有功能保持不变
```

### 与原版导航对比

| 原版导航项 | 改版归属 |
|-----------|---------|
| 工作台 | 工作台（保留，内容调整） |
| 项目管理 | 合并入→ 模型管理/项目列表 |
| 样本管理 | 样本管理（保留不变） |
| 在线推理 | 合并入→ 模型管理/验证推理 Tab |

### 3.11 步骤器的两种模式（设计核心）

**问题背景：**  
用户问：样本库已有样本，能不能直接跳 Step 2？已训练完，能不能直接跳 Step 3 推理？

**解决方案：步骤器区分两种进入模式**

#### 模式一：新建模型（顺序锁定）

```
入口：「新建模型」按钮 → 填基本信息 → 确定进入训练流程

① 上传样本 ──── ② 模型训练 ──── ③ 验证推理 ──── ④ 发布
  蓝色·可点        灰色·不可点      灰色·不可点      灰色·不可点
       ↓
  完成后解锁下一步
```

- 步骤圆圈：已完成=绿色可点（可回看），当前=蓝色，未到=灰色不可点
- 鼠标悬停未解锁步骤：显示 tooltip「请先完成上一步」

#### 模式二：已有模型进入（自由跳转）

```
入口：模型卡片按钮（进入流程 / 查看结果 / 验证推理→）

① 上传样本 ──── ② 模型训练 ──── ③ 验证推理 ──── ④ 发布
  绿✓·可点        绿✓·可点         蓝色·当前        蓝色·可点
     ↑──────────────────────────────────────────────↓
                    所有步骤均可直接点击跳转
```

- 系统自动加载该模型的历史数据（样本已上传、训练已完成）
- 面包屑不显示「新建模型」，直接显示「训练引导」

```
   ▼
Step 1：选择训练样本
   ├─ 上传新文件（拖拽CSV/XLSX）
   └─ 从样本库选择（已有数据直接复用）
   │
   ▼
Step 2：模型训练
   ├─ 设置复杂度 + 验证集比例
   ├─ 点击「开始训练」（30s~2min）
   └─ 展示 Test 集 AUC / KS / F1（不展示Train指标）
   │
   ▼
Step 3：验证推理（合并）
   ├─ Tab「验证」：上传有Y标签样本 → 输出评估指标
   └─ Tab「推理」：填写特征值 → 输出违约概率（Y值）
   │
   ▼
Step 4：确认发布
   └─ 汇总模型信息 → 一键发布 → 进入「已上线」状态
```

## 五、改版前后核心对比

| 维度 | 改版前 | 改版后 |
|------|--------|--------|
| 导航项数量 | 4项（工作台/项目管理/样本管理/在线推理） | 3项（工作台/模型管理/样本管理） |
| 开始建模路径 | 项目管理→模型列表→模型训练（3次跳转） | 模型管理→项目→模型列表→训练（引导式，减少1次） |
| Train 指标 | 展示 Train + Test 两套指标 | 仅展示 Test 集，附说明 |
| 验证与推理 | 两个独立页面 | 同一页面两个 Tab |
| 样本选择 | 每次新建模型都需上传文件 | 支持从样本库直接复用 |
| 新用户引导 | 无引导，需摸索 | 步骤指示器 + 面包屑全程可见 |
